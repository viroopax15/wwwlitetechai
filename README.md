# Lite Tech AI GitHub Pages Static Mirror

This folder is a GitHub Pages-ready version of the exact static mirror in
`outputs/litetechai-option-c`.

It is intended to be deployed at:

https://viroopax15.github.io/wwwlitetechai/

The WordPress/Elementor asset paths are prefixed with `/wwwlitetechai/` so the
site works as a GitHub Pages project site instead of a domain-root site.

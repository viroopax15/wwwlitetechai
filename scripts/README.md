# Lite Tech AI Option C Exact Local Mirror

This is a raw local mirror of the cached Bluehost/WordPress site at `https://litetechai.com`.
It intentionally preserves the original WordPress/Elementor HTML, titles, metadata, classes,
visual layout, scripts, CSS, and assets as closely as possible. The only changes are URL rewrites
needed to load mirrored assets and internal pages from localhost.

Preview:

```bash
python3 -m http.server 4175
```

Open `http://localhost:4175`.
